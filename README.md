# Repaso de Redes y Soporte IT

Página web estática para memorizar los conceptos clave de redes y soporte IT: HTTPS, hub/switch/router, IP estática y dinámica, VPN y diagnóstico en Windows.

## Contenido

- Resumen visual de los 5 bloques, con tablas comparativas y avisos de examen.
- 19 tarjetas de memoria con respuestas y opción de mezclar.
- Quiz de 14 preguntas con puntuación y explicaciones.
- Diseño adaptable a móvil y modo oscuro automático.
- Sin dependencias: HTML, CSS y JavaScript en un solo archivo.

## Cómo usarla

Abre `index.html` en cualquier navegador o publica el repositorio con GitHub Pages.
