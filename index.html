1 HTTPS

Qué es: la versión segura de HTTP. Cifra los datos que viajan entre el navegador del usuario y el servidor web para evitar que sean interceptados o leídos por terceros (ataques Man-in-the-Middle).

CifradoCertificados SSL/TLS
Puerto HTTPSTCP 443
HTTP sin cifrarTCP 80
Enfoque de prueba: si un usuario no puede acceder a una web segura, revisa que el puerto 443 no esté bloqueado en el firewall y que la fecha y hora del PC estén sincronizadas; una hora incorrecta invalida el certificado SSL localmente.

2 Hub vs. Switch vs. Router

Son los pilares físicos de una red. La clave está en la capa OSI en la que opera cada dispositivo.

Dispositivo Capa OSI Identificador que lee Comportamiento Uso
Hub Capa 1 · Física Ninguno (solo pulsos eléctricos) Inunda el tráfico a todos los puertos (broadcast). Genera colisiones. Obsoleto; ya no se usa en redes modernas.
Switch Capa 2 · Enlace de datos Direcciones MAC Reenvía el tráfico solo al puerto del destino usando la tabla CAM. Conectar varios equipos dentro de una misma LAN.
Router Capa 3 · Red Direcciones IP Calcula la mejor ruta y enruta paquetes entre redes distintas. Conectar redes diferentes: LAN ↔ Internet u otra sucursal.
Regla rápida: Hub → capa 1; Switch → capa 2 (MAC); Router → capa 3 (IP).

3 IP estática vs. dinámica

Automática

IP dinámica

La asigna automáticamente un servidor DHCP. Tiene un lease time (tiempo de concesión) y puede cambiar.

Uso ideal: computadoras de usuarios, laptops y smartphones. Facilita la administración masiva.

Manual

IP estática

La configura a mano un administrador en las propiedades de red del equipo y nunca cambia.

Uso ideal: servidores, impresoras de red, cámaras IP e interfaces de routers o switches. Los equipos que brindan servicios deben estar siempre en la misma dirección.

Riesgo: si configuras una IP estática que ya está en uso, provocarás un conflicto de direcciones IP.

4 Red privada virtual (VPN)

Qué es: un túnel cifrado y seguro a través de una red pública (Internet) para proteger los datos corporativos.

Client-to-Site

Acceso remoto

Un empleado en Home Office se conecta a los servidores de la oficina mediante un software cliente, por ejemplo Cisco AnyConnect, OpenVPN o FortiClient.

Site-to-Site

Sitio a sitio

Conecta los routers de dos sucursales físicas para que compartan recursos de red de forma transparente para los usuarios.

Enfoque de prueba: una VPN no «da internet mágico»: necesita una conexión a internet previa funcionando. Su función principal es cifrar el tráfico y dar acceso a recursos internos (IPs privadas) desde el exterior.

5 Windows: diagnóstico y soporte

En una prueba técnica no se evalúa ofimática, sino la capacidad de diagnosticar problemas con herramientas nativas.

Comando Para qué sirve
ipconfigMuestra la IP actual del equipo.
ipconfig /allMuestra IP, dirección MAC, servidor DNS y servidor DHCP.
ipconfig /release → ipconfig /renewSuelta la IP actual y pide una nueva IP dinámica al servidor DHCP. Soluciona muchos problemas locales.
ipconfig /flushdnsBorra la caché DNS. Útil cuando una web cambió de IP y el navegador sigue intentando ir a la IP vieja.
ping [IP o dominio]Comprueba si hay conectividad básica con un destino.
tracert [IP o dominio]Muestra todos los saltos (routers) por los que pasa el paquete; ayuda a ver dónde se corta la conexión.

Administrador de tareas

Matar procesos colgados y ver el consumo de recursos.

Visor de eventos

Revisar los logs del sistema y ver por qué falló una aplicación o por qué se reinició el PC.

Servicios (services.msc)

Reiniciar procesos del sistema. Ejemplo: si la impresora no funciona, reiniciar Print Spooler / Cola de impresión.

Trucos para recordar

  • 80 / 443: HTTP va sin cifrar por el 80; el «S» de Secure añade el 443.
  • 1-2-3: Hub (capa 1), Switch (capa 2, MAC) y Router (capa 3, IP).
  • DHCP = dinámica; configurada a mano = estática.
  • HTTPS falla: revisa el puerto 443 y la hora del equipo.
  • Sin internet no hay VPN: el túnel viaja sobre una conexión existente.
